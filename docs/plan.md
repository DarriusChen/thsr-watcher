# 垂直切片計畫

目前實作範圍為 VS-01～VS-03，依 [AGENTS.md](../AGENTS.md) 執行。
VS-04～VS-06 是未來構想，尚未實作，也不屬於目前授權範圍。
實際使用方式見 [README](../README.md)，線上驗證狀態見
[verification](verification.md)。

| Slice | 使用者可以完成什麼 | 完成邊界 |
|---|---|---|
| **VS-01：公開時刻表查詢**（已完成） | 查路線、日期與時段內的班次 | 顯示時刻表，不代表有票 |
| **VS-02：可訂車次查詢**（已完成） | 人工輸入驗證碼後，取得可訂車次 | 驗證碼明確遭拒才可重填，同一 session 最多 3 次 |
| **VS-03：本機訂位完整流程**（已實作） | 先儲存本機 preset → 查票 → 自己選車 → 使用 preset 送出一次 → 取得訂位結果 | 選車後直接送出，不再詢問個資或二次確認；不付款、不重送；回報確認、拒絕、不確定或未送出 |
| **VS-04：LINE Bot 查票** | 在 LINE 輸入條件、接收驗證碼圖片、回覆答案、查看可訂車次 | 打通 LINE 與查票 session，處理逾時及不同使用者的隔離 |
| **VS-05：LINE Bot 訂位** | 在 LINE 選車並確認訂位，收到訂位結果 | 沿用 VS-03；個資透過適當的私密輸入流程提供 |
| **VS-06：餘票監看與通知** | 設定監看條件，有符合車次時收到 LINE 通知 | 保守查詢、可停止、避免重複通知；需要驗證碼時交回人處理 |
